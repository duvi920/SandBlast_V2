## 1. 콘텐츠 확장

### 1-1. 새로운 셀 타입

현재 16종으로 기본 상호작용은 충분하지만, 아래 타입을 추가하면 전술 깊이가 크게 늘어난다.

| 타입 | 분류 | 핵심 동작 | 기대 효과 |
|------|------|-----------|-----------|
| **얼음 (ICE)** | 고체 | 물과 접촉 시 동결, 용암에 녹아 물 생성 | 지형 동결 전략, 얼음 다리 |
| **산성 액체 (ACID)** | 액체 | 고체 셀 천천히 용해 | 은폐 지점 제거, 사다리 녹이기 |
| **전기 (ELECTRICITY)** | 에너지 | 전도성 셀 따라 순간 전파, 물과 반응 | 함정 배치 메타 |
| **씨앗 (SEED)** | 분말 | 흙(DIRT) 위에서 나무(WOOD)로 성장 | 실시간 지형 재생 |
| **증기 (STEAM)** | 기체 | 물+용암 접촉 시 생성, 상승 후 소멸 | 시야 차단 전술 요소 |

### 1-2. 완드·스펠 시스템 확장

**현재 구조:** `SpellData` 버퍼에 ProjectileType 4종 + Modifier 2종 (MultiShot, Penetrate)

**개선 방향:**

- **Modifier 추가**
  - `Bounce` — 벽 반사 (코드에 미구현 표시 있음)
  - `Homing` — 가장 가까운 적에게 유도
  - `Delayed` — 착탄 N틱 후 폭발
  - `Chain` — 첫 타격 후 인근 적에게 연쇄

- **스펠 조합 (Spell Combo)**  
  두 `SpellData` 슬롯을 동시에 충족하면 새로운 효과 발현.  
  예) `Explosion` + `LiquidSpray(Lava)` → 용암 폭발탄

- **완드 등급 시스템**  
  Common / Rare / Legendary 3단계. 등급에 따라 마나 소모·쿨다운 차이.

### 1-3. 새로운 게임 모드

| 모드 | 인원 | 설명 |
|------|------|------|
| **점령전 (Control)** | 2v2 / 4v4 | 중앙 구역을 점령하면 점수 누적, 먼저 임계점 도달 팀 승리 |
| **생존전 (Last Stand)** | FFA 4인 | 팀 없음, 용암 상승 속도 빠름, 개인 생존 순위 |
| **샌드박스** | 1~2인 | 자유 물질 배치 + 물리 실험, 멀티플레이 공동 제작 |
| **타임어택** | 솔로 | 제한 시간 내 픽셀 파괴량 경쟁 |

### 1-4. 캐릭터·클래스 시스템

현재 플레이어는 외형만 다름. 클래스를 도입하면 meta 다양성 확보.

| 클래스 | 특성 |
|--------|------|
| **Mage** | 마나 최대치 +30%, 이동속도 -10% |
| **Scout** | 대시 쿨다운 -40%, HP -15 |
| **Berserker** | 근거리 폭발 피해 +25%, 원거리 완드 슬롯 1개 |

> 구현 비용 최소화: `PlayerGhostData`에 `ClassType` 필드 추가 + `SimulationConstants`에 클래스별 오프셋 테이블.

## 2. 게임플레이 심화

### 2-1. 매치메이킹 & 로비

현재 `RoomWatchSystem`은 접속자 수만 감지하는 수준. 확장 필요:

1. **빠른 매칭** — 래이턴시·레이팅 기반 자동 매칭 (Unity Relay/Lobby 패키지 활용)
2. **친구 초대** — 파티 코드 입력, 비공개 방 생성
3. **관전 모드** — 진행 중인 방에 관전자로 입장, 청크 동기화만 수신

### 2-2. 랭크 & 시즌

| 구성 요소 | 세부 내용 |
|-----------|-----------|
| **MMR 시스템** | 승·패·KDA 가중 점수, Elo 변형 |
| **시즌** | 8주 단위, 시즌 끝에 보상(완드 스킨·칭호) 지급 |
| **리더보드** | 파괴한 픽셀 수, 평균 생존 시간, 다중 집계 지표 |

### 2-3. 튜토리얼

신규 플레이어 이탈 방지를 위한 인터랙티브 튜토리얼:

1. **물질 상호작용 실험실** — 각 셀 타입 소개 (샌드박스 씬 활용)
2. **이동·대시 연습** — 장애물 코스
3. **완드 조합 가이드** — 스펠 슬롯 구성 안내
4. **첫 매치 동행** — AI 봇과 1v1 연습

## 3. 맵·아레나 개선

### 3-1. 맵 다양성

| 맵 아이디어 | 특징 |
|-------------|------|
| **화산 분화구** | 중앙에서 용암이 간헐적으로 분출, 다리 파괴 압박 |
| **수중 동굴** | 물로 채워진 하단, 독 액체 구역 |
| **폐허 성채** | SOLID_INDESTRUCTIBLE 기둥, 목재(WOOD) 구조물 |
| **모래 사막** | 모래(SAND)가 대부분, 지형이 빠르게 변형 |

### 3-2. 맵 이벤트 시스템

매치 진행 중 랜덤 이벤트 발생:

- **유성우** — 무작위 위치에 폭발형 투사체 낙하
- **지진** — 전체 지형 일부 픽셀 랜덤 낙하
- **보물 상자** — 강화된 완드 아이템 일시 스폰

### 3-3. 유저 맵 에디터 공개

현재 `ArenaMapEditorWindow`는 에디터 전용. WebGL 빌드에서도 동작하는 런타임 에디터로 확장:

- 픽셀 브러시로 직접 맵 설계
- 완성된 맵을 JSON으로 내보내기·가져오기
- 커뮤니티 맵 공유 허브 (백엔드 필요)

## 4. 플레이어 경험 (UX/UI)

### 4-1. HUD 개선

현재 `ArenaHudBehaviour`는 IMGUI 기반. UI Toolkit 또는 uGUI로 전환 권장:

- HP/마나 바 애니메이션 (데미지 시 흔들림)
- 미니맵 (픽셀 그리드 다운샘플링)
- 스코어보드 단축키 (Tab)
- 킬피드 (오른쪽 상단)

### 4-2. 리플레이 시스템

- 서버가 매 틱 `PixelGridDeltaRpc` + 입력 로그를 저장
- 클라이언트에서 재생 (배속 조절, 시점 전환)
- 하이라이트 클립 자동 추출 (킬·폭발 N초 전후)

### 4-3. 사운드 & 이펙트

현재 사운드 시스템 미구현. 우선순위:

1. 셀 타입별 충돌음 (불 타오름, 용암 흐름, 폭발)
2. 완드 발사음·충전음
3. 플레이어 피격·사망음
4. 배경 앰비언스 (맵별 테마)

## 5. 기술·플랫폼 확장

### 5-1. WebGL 최적화

현재 `WebGL_Plan.md`에 계획만 있음. 구체적 작업:

- `FixedBytes4096` RPC 직렬화 WebGL 호환성 검증
- Burst→Managed 폴백 (WebGL에서 일부 Job 제한)
- 메모리 제한 대응 (`NativeArray` 풀링)

### 5-2. 모바일 지원 검토

- 터치 입력 레이어 (가상 조이스틱, 탭 투 대시)
- 픽셀 그리드 해상도 축소 (256×256 → 128×128) 옵션
- 배터리 절약 모드 (시뮬레이션 TPS 15로 다운클럭)
