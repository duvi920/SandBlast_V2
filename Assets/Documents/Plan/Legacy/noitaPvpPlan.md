# Noita Pvp Plan

> 작성일: 2026-04-25  
> 현재 프로젝트: SandBlast (v0.1.0)  
> 목표: 노이타 스타일 픽셀 물리 기반 PvP 대전 게임 (1v1 / 2v2)

---

## 0. 핵심 컨셉

**"지형이 살아있는 배틀 게임"**

모든 픽셀이 물리 반응을 갖는 파괴 가능한 아레나에서 완드(마법 무기)로 싸웁니다.  
단순 조준·사격이 아니라 **지형 파괴·액체 흘리기·연쇄 폭발**이 전술이 됩니다.

### 차별점

| 일반 배틀 게임 | 노이타플러스베틀물 |
|---|---|
| 맵이 고정된 배경 | 맵 자체가 파괴·변형되는 물질 |
| 총/스킬 데미지 계산 | 픽셀 CA 물리 반응이 전투 결과를 만듦 |
| 정해진 스킬 셋 | 완드 슬롯 조합으로 빌드 다양성 |

---

## 1. 지원 모드

### 1v1 — 아레나 듀얼

- 소규모 밀폐형 맵 (약 512×512 px)
- 맵 중앙에 자원(완드·스펠) 배치 → 초반 러시/회피 선택지
- 제한 시간 내 미결 시 맵 외곽 용암 상승으로 강제 결판

### 2v2 — 팀 아레나

- 중간 규모 맵 (약 1024×512 px), 좌우 팀 진영 분리
- 팀원 부활 1회 (파트너가 살아있을 때만)
- 지형 통제 전술이 핵심: 통로 막기, 낙하 함정, 액체 범람

---

## 2. NetCode 설계 방침

최대 4명(2v2)이므로 픽셀 그리드 동기화가 관리 가능한 범위입니다.

```
서버 (권위적 시뮬레이션)
 ├── 픽셀 CA 전체 계산
 ├── 변경된 셀만 델타 압축 → 클라이언트 전송  ← P0 부채
 └── 플레이어 입력 수신 + 결과 브로드캐스트

클라이언트 (예측 + 렌더링)
 ├── 로컬 플레이어 입력 예측 (기존 PredictedSimulationSystemGroup)
 └── 서버 그리드 델타 수신 → 로컬 그리드 패치
```

### 대역폭 추정 (2v2 기준)

| 항목 | 수치 |
|---|---|
| 활성 청크 (4명 분산) | 최대 20~30개 |
| 청크 델타 압축 후 | 약 5~15KB/틱 |
| 30틱/초 서버 전송량 | 약 150~450KB/s |

청크 슬리핑 최적화가 이미 구현되어 있어 비활성 영역은 전송하지 않습니다.

## 3. 픽셀 물질 — PvP 관련 요소만

전술적으로 의미 있는 물질만 우선 구현합니다.

### 3.1 고체

| 물질 | CellType | PvP 역할 |
|---|---|---|
| 돌 | `SOLID_STATIC` | 기본 지형, 폭발로 파괴 |
| 흙 | `SOLID_DIRT` | 파괴 쉬움, 동굴 전술 |
| 나무 | `SOLID_WOOD` | 불에 연소 → 지형 붕괴 연쇄 |
| 화약 | `SOLID_GUNPOWDER` | 배치형 트랩, 연쇄 폭발 |

### 3.2 액체 (최소한으로)

| 물질 | CellType | PvP 역할 |
|---|---|---|
| 용암 | `LIQUID_LAVA` | 진입로 차단, 낙하 트랩 |
| 독 | `LIQUID_POISON` | 지역 거부, 장기 피해 |

> 산·기름·혈액 등 나머지 액체는 Phase 4 이후 추가 여부 판단

### 3.3 반응 매트릭스 (PvP 핵심)

```
나무 + 불       → 연소 → 지형 붕괴
화약 + 불/충격  → 폭발 → 주변 셀 파괴 + 플레이어 넉백
용암 + 흙       → 화산암(SOLID_BASALT) 생성 → 통로 차단
독 + 넓은 공간  → 확산 → 구역 거부
```

## 4. 완드(마법 무기) 시스템

### 4.1 구조

```
WandComponent
 └── SpellSlot[8]
      └── SpellData
           ├── ProjectileType   // 탄환·광선·폭발
           ├── LiquidPayload    // 방출 액체 (없음·용암·독)
           ├── Modifier         // 멀티샷·관통·반사
           └── ManaCost
```

### 4.2 PvP 완드 빌드 예시

| 빌드명 | 조합 | 전략 |
|---|---|---|
| 지형 파괴형 | 폭발 탄환 × 4 + 멀티샷 | 지형을 빠르게 부수고 낙하 유도 |
| 용암 범람형 | 용암 방사 × 3 + 광역 | 진영 앞 용암 풀 형성 |
| 독 지뢰형 | 독 탄환 × 2 + 지연 폭발 | 통로에 독 웅덩이 설치 |
| 관통 저격형 | 관통 탄환 × 1 + 고속 | 벽 너머 직선 딜 |

### 4.3 신규 ECS 시스템

| 시스템 | 역할 |
|---|---|
| `WandCastSystem` | 입력 → 주문 발동, 마나 소모, 쿨다운 |
| `SpellProjectileSystem` | 투사체 이동·픽셀 충돌·피해 판정 |
| `LiquidSpraySystem` | 액체 방사 스폰 (BulletMoveSystem 확장) |
| `ManaRegenSystem` | 마나 회복 틱 |
| `WandPickupSystem` | 맵 내 완드 획득 처리 |

### 4.4 신규 ECS 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| `WandComponent` | 슬롯 배열, 마나, 쿨다운 타이머 |
| `SpellData` (IBufferElementData) | 개별 주문 데이터 |
| `ManaComponent` | 현재/최대 마나, 회복 속도 |
| `ProjectileComponent` | 투사체 유형·페이로드·피해량 |

## 5. 아레나 맵 구성

### 5.1 맵 생성 방식

절차적 완전 생성 대신 **템플릿 기반 + 부분 랜덤**으로 구현 비용을 낮춥니다.

```
MapTemplate (에디터에서 사전 제작)
 ├── 기본 지형 레이어  (돌/흙 배치)
 ├── 스폰 포인트        (플레이어·완드·자원)
 └── 랜덤 시드 구역    (일부 공간만 CA로 변형)
```

### 5.2 1v1 맵 구조

```
[ 스폰A ] ── 통로 ── [ 중앙 자원 ] ── 통로 ── [ 스폰B ]
              파괴 가능한 흙/나무 지형
              중앙 하단에 용암 웅덩이
```

### 5.3 2v2 맵 구조

```
[ A팀 진영 ] ── 중앙 전선 ── [ B팀 진영 ]
   스폰×2          자원 배치           스폰×2
              수직 구조 (상하 복층)
              복수의 우회 통로
```

## 6. 기술 부채 및 선행 과제

전환 전에 반드시 해결해야 할 기존 미구현 항목입니다.

| 우선순위 | 항목 | 파일 |
|---|---|---|
| **P0** | 픽셀 그리드 RPC — 변경 셀 델타 압축 동기화 | `Systems/Simulation/` (신규) |
| **P0** | `PlayerMoveSystem` 픽셀 지형 완전 충돌 처리 | `Systems/Movement/PlayerMoveSystem.cs` |

## 7. 단계별 마일스톤

```
Phase 1 — 기술 부채 해소 (2주)
  · 픽셀 그리드 RPC 델타 동기화 구현  ← 가장 중요
  · PlayerMoveSystem 픽셀 충돌 완성
  · PlayerVisualSystem 완성, PlayerController.cs 제거

Phase 2 — 완드 시스템 (3주)
  · WandComponent / SpellData 구조 구현
  · WandCastSystem, SpellProjectileSystem
  · LiquidSpraySystem (용암·독 방사)
  · ManaRegenSystem, WandPickupSystem

Phase 3 — 픽셀 물질 확장 (2주)
  · 흙(SOLID_DIRT), 나무(SOLID_WOOD), 화약(SOLID_GUNPOWDER) 추가
  · 독(LIQUID_POISON) 추가
  · 반응 매트릭스 구현 (나무+불, 화약+충격, 용암+흙)

Phase 4 — 아레나 맵 (2주)
  · 맵 템플릿 에디터 도구 제작
  · 1v1 맵 1종 완성
  · 2v2 맵 1종 완성
  · 스폰·자원 배치 시스템

Phase 5 — 게임 모드 로직 (2주)
  · 승패 판정 (사망·시간 초과·용암 상승)
  · 팀 부활 시스템 (2v2)
  · 점수판 / 결과 화면 UI
  · 체력·마나 HUD
```

**총 예상 일정: 약 11주**
